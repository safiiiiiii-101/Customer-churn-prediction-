## E-Commerce Customer Churn Prediction

An end-to-end machine learning and predictive analytics system designed to identify at-risk e-commerce customers and support data-driven customer retention strategies.

The project analyzes 5,630 customer records across 18 predictive features and implements comprehensive exploratory data analysis, automated preprocessing, data leakage prevention, model benchmarking, hyperparameter optimization, and explainable AI.

Five machine learning algorithm families were evaluated: Logistic Regression, Random Forest, XGBoost, LightGBM, and CatBoost. The optimized Random Forest achieved 96.35% accuracy and an 88.64% F1-score on the development-test dataset.

The trained model is integrated into an interactive, multipage Streamlit application featuring:

- Individual customer churn prediction
- Customer analytics dashboard
- Machine learning model comparison
- SHAP explainability and permutation feature importance
- Bulk CSV prediction with downloadable results
- Automated preprocessing and model inference

The project demonstrates the complete machine learning lifecycle, from raw data exploration to an interactive prediction application.
